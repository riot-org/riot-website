# Riot 官网

Riot 产品站。静态页面，用浏览器直接打开 `index.html` 即可预览。

[产品仓库](https://github.com/riot-org/Riot)
</div>

## 本地预览

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>。下载按钮会去读 [Riot Releases](https://github.com/riot-org/Riot/releases/latest) 的最新安装包。
